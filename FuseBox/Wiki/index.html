FuseBox Datapack Wiki & API

High-performance Minecraft datapack framework for reactive events, actionbar stopwatches, and countdowns.

Alpha 0.1

🚀 Getting Started

FuseBox handles complex NBT parsing, item detection, and actionbar UI management out-of-the-box in Minecraft 1.20.5+ / 1.21+.

Feature Function Call Description
Debug Diagnostic Mode /function fb:debug/menu Opens in-game debug chat menu to toggle event and timer diagnostics.
Reset Event Database /function fb:event/reset_db Clears all registered callbacks and scoreboards.

⚡ Event Registration API

Register reactive player events with item_id and custom_data filters.

Event Name Trigger Condition Example NBT Filter
onRightClick Player right-clicks with carrot or fungus on a stick {wand_type:"fire"} or {id:"ascend"}
onHoldItem Player holds specified item in mainhand or offhand {id:"speed_stick"}
onJoin Player joins the world None
onDeath Player dies None
