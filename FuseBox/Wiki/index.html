FuseBox Documentation & API

High-performance Minecraft datapack framework for reactive events, stopwatches, and countdowns.

Framework Overview
Function Description
/function fb:debug/menu Opens the in-game debug chat diagnostic menu.
/function fb:event/reset_db Clears all registered event callbacks and scoreboards.
Supported Events
Event Name Trigger Condition
onRightClick Right-clicks with carrot or fungus on a stick
onHoldItem Holds item in mainhand or offhand
onJoin Player joins world
onDeath Player dies
Stopwatch & Countdown API
Command Description
/function fb:sw/create {name:"demo"} Creates a stopwatch.
/function fb:cd/create {name:"timer1",h:0,m:1,s:30,cmd:'...'} Creates a countdown with expiry command.
