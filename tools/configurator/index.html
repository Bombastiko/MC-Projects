FuseBox Datapack Documentation

Learn how to control stopwatches, countdowns, manage display registers, and debug NBT storages.

🚀 Quick Start (Stopwatch)

To start using FuseBox stopwatches, reload the datapacks and run the following commands:

/reload
/function fb:sw/create {name:"demo"}

This creates a stopwatch named demo and registers it in the active list.

⏳ Quick Start (Countdown Timer)

To create, run and display a countdown timer, execute the following commands:

# 1. Create a timer named 'my_timer' for 1 minute and 30 seconds
/function fb:cd/create {name:"my_timer",h:0,m:1,s:30,on_complete:"say Time is up!",animation:"flash"}

# 2. Start the timer ticking
/function fb:cd/start {name:"my_timer"}

# 3. Register actionbar display layout for all players (@a)
/function fb:cd/display_ab_custom {player:"@a",cd:"my_timer",format:"digital_short",color:"red",color_sec:"yellow",color_num:"white",prefix:"Time Left: ",suffix:"",bold:"false",global_type:"soft"}

⏱ Controlling Timers & Countdowns

Timers and countdowns can be paused, resumed, and deleted dynamically using their names.

Action Stopwatch Command Countdown Command
Start (Starts automatically upon creation) /function fb:cd/start {name:"demo"}
Pause /function fb:sw/pause {name:"demo"} /function fb:cd/pause {name:"demo"}
Resume /function fb:sw/resume {name:"demo"} /function fb:cd/resume {name:"demo"}
Delete /function fb:sw/delete {name:"demo"} /function fb:cd/delete {name:"demo"}

⚙ Display Priorities

You can choose to register a custom display configuration for any player or group of players:

  • Global Configuration: Use @a as the player. You can choose between:
    • soft: Displays to everyone except those with an individual configuration.
    • hard: Forcefully displays to everyone, overriding any custom configs.
  • Individual Priority: Setting a config for a specific player (e.g. oneBombastiko) overrides soft global layouts.

Reset Display: To clear a player's actionbar layout, run:

/function fb:display/ab/clear {player:"oneBombastiko"}

🛠 Troubleshooting & Debugging

FuseBox has a robust built-in logging system to inspect scores and NBT storage values.

Toggle Debug Mode: Enable or disable debug chat messages.

# Turn Debug Mode ON
/data modify storage fb:config debug set value 1b

# Turn Debug Mode OFF
/data modify storage fb:config debug set value 0b

Dump System Info: Output scoreboard data and registers:

# Stopwatch Debug
/function fb:sw/debug_info

# Countdown Debug
/function fb:cd/debug_info

Full Storage Reset: Completely clear all databases:

# Reset Stopwatches
/function fb:sw/reset-db

# Reset Countdowns
/function fb:cd/reset-db
